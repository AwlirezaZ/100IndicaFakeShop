# 100Indica Shop — demo shop with a pretend checkout

**▶ Live site: https://awlirezaz.github.io/100IndicaFakeShop/**

It's rebuilt and published automatically every time something is pushed to `main`
(see [.github/workflows/pages.yml](.github/workflows/pages.yml)).

## How to use it (no install needed)

1. Copy **`100IndicaShop.html`** to the Mac (AirDrop, USB, email — anything).
2. Double-click it. It opens in Safari or Chrome.
3. Shop, add things to the cart, and check out with **any** name, address and card number.
   - Press **"Autofill demo details"** on the checkout page to fill everything in one click.
   - When asked for a verification code, any 6 digits work.
   - A card number ending in **0000** is always declined, so you can see the error screen.
4. The 🌙 / ☀️ button in the top bar switches night mode on and off. By default it follows the Mac's own setting.

## Where the products come from

| Source | What | Loaded |
|---|---|---|
| [DummyJSON](https://dummyjson.com) | ~200 electronics, fashion, home and beauty items | bundled into the file (with thumbnails) |
| [Open Library](https://openlibrary.org) | books (real titles, authors, covers and ratings) | bundled into the file |
| [Open Food Facts](https://world.openfoodfacts.org) | groceries (real products, brands, photos, Nutri-Score) | bundled into the file |
| [Open Beauty Facts](https://world.openbeautyfacts.org) | shampoo, skincare, toothpaste… | bundled into the file |

The open-data sources have no prices, so **prices, discounts and stock are generated** (always the same for the same
product). Food and beauty ratings are generated too; book ratings are real Open Library ratings.

All products are downloaded by `npm run refresh-products` and saved in `src/data/catalog.json` and
`src/data/dummyjson.json`. They're bundled rather than fetched live because Open Food Facts only allows about 10
searches a minute, and dummyjson.com is blocked on some networks (which used to leave the shop with no electronics).

## For developers

```bash
npm install
npm run dev               # live development server at http://localhost:5173
npm run refresh-products  # re-download the bundled catalog (takes a few minutes)
npm run build             # rebuilds "100IndicaShop.html" (one self-contained file)
```

Built with React, Vite, Tailwind CSS, Zustand and React Router (hash routing, so it works from a file).
